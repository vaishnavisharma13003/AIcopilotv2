# Backend - AI Job Copilot

FastAPI backend. See the top-level `README.md` in the project root for the
full setup guide, testing checklist, and interview prep notes. This file
just covers backend-only quick reference.

## Quick start

```bash
cd backend
python -m venv venv
venv\Scripts\activate        # Windows
# source venv/bin/activate   # macOS/Linux

pip install -r requirements.txt
copy .env.example .env       # Windows
# cp .env.example .env       # macOS/Linux

uvicorn main:app --reload --port 8000
```

Make sure Ollama is running first: `ollama run llama3.2`

API docs (auto-generated by FastAPI) once running: http://localhost:8000/docs

## Files

| File | Purpose |
|---|---|
| `main.py` | FastAPI app + all HTTP endpoints |
| `rag.py` | Manual RAG (chunking/FAISS/embeddings written by hand) |
| `langchain_rag.py` | Same RAG job, built with LangChain instead |
| `langgraph_workflow.py` | Multi-step LangGraph pipeline |
| `agent.py` | LLM tool-calling demo |
| `mcp_server.py` | MCP server exposing job tools |
| `mcp_client.py` | Standalone script that talks to the MCP server |
| `evaluation.py` | Scores an answer's relevance/groundedness/hallucination/completeness |
| `jobs.json` | DEMO job data used by the MCP server |
